> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sửa giao diện NiceGUI (`src/ui/web/`) theo kết quả đánh giá Impeccable: trạng thái và số liệu nói thật, bỏ khung mẫu chatbot AI, gom công cụ nghiên cứu, chữ đủ lớn và đủ tương phản, đưa "căn cứ áp dụng tại ngày sự việc" lên đầu câu trả lời, dùng được trên điện thoại.

**Architecture:** Giữ nguyên cấu trúc file và luồng gọi API. Logic mới là các hàm thuần (dễ test): `connection_status`, `status_text`, `law_validity`, `applicable_basis`, `corpus_stats`, `shell_classes`. Phần còn lại là sửa bố cục, chữ, CSS; kiểm bằng ảnh chụp (Electron) và bộ phát hiện Impeccable qua CDP.

**Tech Stack:** Python 3.14, NiceGUI (Quasar + Tailwind class), httpx, unittest/pytest. Không thêm thư viện.

**Spec:** bản đánh giá `.impeccable/critique/2026-11-10T09-27-14Z__src-ui-web.md` (ngoài git, đọc trong phiên) và quyết định của Đạt ngày 10/11: làm cả 5 vấn đề; diện mạo "văn bản pháp lý" (serif tiếng Việt cho văn bản luật và câu trả lời, ít màu); công cụ nghiên cứu gom vào mục thu gọn "Chế độ nghiên cứu".

    assert law_validity("BLLD2012", "2020-05-01") == ("Có hiệu lực tại ngày 01/05/2020", "ok")
    assert law_validity("BLLD2019", "2020-05-01") == ("Chưa có hiệu lực tại ngày 01/05/2020", "warn")

def test_applicable_basis():
    def resp(ids, date=None, refused=False):
        trace = [{"node": "route", "output": {"route_type": "temporal", "event_date": date}}]
        return AskResponse(answer="a", refused=refused, trace=trace,
                           citations=[{"chunk_id": i} for i in ids])
    assert applicable_basis(resp(["BLLD2012_Dieu37_Khoan1"], "2020-05-01")) == \

    assert applicable_basis(resp(["BLDS2015_Dieu357_Khoan1", "LTM2005_Dieu306"])) == \
        "Căn cứ: Bộ luật Dân sự 2015 (còn hiệu lực); Luật Thương mại 2005 (còn hiệu lực)."

        "Căn cứ: Bộ luật Lao động 2012 (hết hiệu lực từ 01/01/2021)."
    assert applicable_basis(resp(["BLLD2012_Dieu37_Khoan1"], "2020-05-01", refused=True)) is None
